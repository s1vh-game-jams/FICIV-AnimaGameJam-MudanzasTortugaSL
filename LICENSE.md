## 1. Intended licensing direction

The initial licensing request combines three ideas:

- **Attribution (BY)**
- **ShareAlike (SA)**
- **NoDerivatives (ND)**

Creative Commons does **not** offer a standard `BY-SA-ND` license.

`SA` is a condition applied to adaptations that are shared, while `ND` prevents sharing adaptations in the first place. Creative Commons therefore offers `BY-SA` and `BY-ND` as separate choices, not a combined license.

Creative Commons also recommends using a software-specific license rather than a CC license for source code.

For those reasons this file is intentionally a **temporary licensing boundary**, not an invented Creative Commons license.

## 2. Original non-software creative material

Until the project owners make a final licensing decision, original project documentation and original creative assets that do not carry another explicit notice are intended to use the closest standard Creative Commons expression of the current "attribution + redistribution of originals + no shared derivatives" requirement:

**Creative Commons Attribution-NoDerivatives 4.0 International — CC BY-ND 4.0**

Official license:
https://creativecommons.org/licenses/by-nd/4.0/

In practical terms, subject to the full license:

- attribution is required;
- unchanged copies may be shared;
- modified/adapted versions may not be distributed without separate permission.

### About the requested ShareAlike condition

A ShareAlike requirement cannot simultaneously operate as a standard CC condition on distributed derivatives if distribution of derivatives is prohibited by `ND`.

If the project later decides that modified creative works **should** be redistributable provided they stay under the same license, the appropriate direction would instead be **CC BY-SA 4.0**.

That choice must be made explicitly; agents must not make it on behalf of the project owners.

## 6. Audio reservation

Audio is intentionally **not finalized by this notice**.

When audio is added, its licensing may require a separate section/file because tracks, sound effects, performances, recordings, generated audio, and commissioned work may carry different terms.

Before a public release containing audio:

1. inventory every audio resource;
2. record its source and license;
3. preserve required attribution;
4. document whether redistribution outside the game build is allowed;
5. update this licensing notice if necessary.

# Interface fonts

Self-hosted Latin subsets (Google Fonts, retrieved 2026-10-05) for the typography confirmed in `/docs/DESIGN.md` §5.
Bundled through `src/styles/fonts.css`, so Vite rewrites their URLs for both root and GitHub Pages subpath builds.

| File | Family | Weights | License |
|---|---|---|---|
| `fredoka-latin.woff2` | Fredoka (variable) | 300–700 | SIL Open Font License 1.1 — `Fredoka-OFL.txt` |
| `nunito-latin.woff2` | Nunito (variable) | 200–1000 | SIL Open Font License 1.1 — `Nunito-OFL.txt` |
| `permanent-marker-latin.woff2` | Permanent Marker | 400 | Apache License 2.0 — `PermanentMarker-LICENSE.txt` |

The Latin subset covers Spanish (á é í ó ú ñ ¿ ¡) and the ↑/↓ arrows used in key hints.
